# Bundled Fantasy Map Generator

This directory is based on Azgaar's Fantasy Map Generator commit:

`403a670055b1a3f30373a64841eb2efe7b5e4688`

Upstream: https://github.com/Azgaar/Fantasy-Map-Generator

The complete source is included under the original MIT license. Local desktop helpers are retained. Run `../github-download/Download Requirements and Build.cmd` once to download the locked dependencies and build the Electron desktop version, then use `../github-download/Launch Fantasy Map Generator.cmd`. It opens as a desktop application, not a browser-hosted local website.

`node_modules`, compiled output and release packages are not committed because the setup script reproduces them from `package-lock.json`.
