# Original source world

`Maptest1.json.zip` contains the original high-resolution `Maptest1.json` exported from Fantasy Map Generator. Districts uses the smaller derived `terrain-cells.bin` at runtime, but the original is preserved here so anyone can reopen the world in the bundled Fantasy Map Generator or reproduce future terrain extracts.

Extract the ZIP before opening the JSON file. The archive only compresses the original file; it does not alter or remove any layers.
